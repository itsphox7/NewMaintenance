NewMaintenance is a paper plugin, that allows you to set your server in maintenance mode with advanced features. 

This plugin is fully customizable, you can change everything.

---

Features
- ✅ Set your server in maintenance mode
- ✅ People with the permission `newmaintenance.bypass` can join in maintenance mode
- ✅ Change every message in `messages.yml`
- ✅ Disable update checks in `config.yml`
- ✅ Change your motd in maintenance mode (soon)
